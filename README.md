# Athlete Train

Ücretsiz statik antrenörlük sitesi.

GitHub Pages:
1. GitHub'da Public repository oluştur.
2. Bu klasördeki 3 dosyayı (`index.html`, `style.css`, `script.js`) yükle.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. GitHub'ın verdiği Pages adresini aç.

Oyuncu, maç ve not kayıtları bu sürümde tarayıcıdaki localStorage'da tutulur; gerçek kulüp kullanımı için daha sonra güvenli giriş/veritabanı eklenmelidir.
